# Remember Palestine

Live, open-source data platform showing the human impact in Palestine. Built with [Tech for Palestine](https://data.techforpalestine.org) open APIs.

## Features

- **Live data** — Pulls real-time statistics from Tech for Palestine's API
- **Names section** — Children killed, counted by first name
- **Data dashboard** — Gaza, West Bank, visual dot-scale, infrastructure tabs
- **Take action** — Verified aid orgs, representative contact links, sharing
- **Developer section** — API endpoints and code snippets for building with the data
- **Responsive** — Dark theme, smooth animations, mobile-friendly

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- No external UI libraries — all custom CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Data Source

All data comes from [data.techforpalestine.org](https://data.techforpalestine.org) — open-source, publicly verifiable, updated daily. No API key required.
